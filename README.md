# Healthdataton — Patient Similarity Network v1.0.0

환자별 기준 시점 이전 임상 특성을 네트워크로 탐색하는 로컬 시각화 도구입니다. CSV를 읽어 외부 라이브러리·서버 없이 브라우저에서 사용할 수 있는 HTML을 생성합니다.

## 기능

- 환자를 노드, 유사한 환자 관계를 연결선으로 표시
- 원본 관측값 기반 거리 계산, 결측·이상치 플래그 처리
- 후보 수·거리 상한·공통 유효 변수 수 필터
- 투약 기록·성별·유효 변수 수에 따른 색상 변경
- 노드 호버 시 기본 정보와 주요 측정값 표시
- 노드 클릭 시 오른쪽에 선택 환자와 연결 환자 정보 표시
- 연결 환자 선택 시 9개 변수와 차이를 나란히 비교
- 기준 환자 변경, 가명 검색, 확대·축소·이동

## 실행

Python 3.11 이상을 사용합니다. Python 3.12.14에서 검증했습니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python build_network.py --input /absolute/path/features_raw.csv --output-dir output
```

`output/patient_similarity_network.html`을 브라우저에서 엽니다. `patient_network_edges.csv`와 `network_summary.json`도 같은 디렉터리에 생성합니다. 강조할 예시 환자는 `--example-index 2`처럼 CSV의 0부터 시작하는 행 번호로 지정할 수 있습니다. 기본값은 첫 번째 행입니다.

## 입력 형식

한 행이 환자별 ICU 체류의 요약 특성인 UTF-8 CSV를 사용합니다.

| 구분 | 필수 컬럼 |
|---|---|
| 비교 변수 | `age`, `weight_kg`, `sbp`, `hr`, `spo2`, `creatinine`, `bun`, `sodium`, `potassium` |
| 표시·비교 조건 | `sex`, `age_under18`, `diuretic_given`, `hf_any`, `mv_pre6h` |
| 시간 품질 | `t0_after_icu_out`, `t0_after_death` |

- 수치 비교 변수에는 결측을 허용합니다.
- 성별 코드는 이 버전에서 `F`, `M`만 지원합니다. 이진 플래그는 결측 없는 `0` 또는 `1`이어야 합니다.
- 비교 변수의 `<변수명>_missing_outlier`가 있으면 1인 값은 거리 계산에서 제외합니다. 선택 사항인 플래그를 생략하면 해당 이상치 제외는 수행하지 않습니다.
- 원본 식별자는 출력하지 않으며 입력 행 순서에 따라 `P0001` 형태의 가명을 부여합니다. 행 순서가 바뀌면 가명도 바뀝니다.
- 최소 2행이 필요합니다. 모든 환자를 노드로 유지하며 유효 비교 조건을 충족하지 못한 환자는 고립 노드가 됩니다.

## 연결 방식과 해석

공통 유효 변수가 최소 5개이고 `age_under18` 플래그가 같은 환자끼리 비교합니다.

```text
거리 = 공통 유효 변수의 |차이| / 전체 환자별 변수 IQR의 평균
     + 0.3 × (9 − 공통 유효 변수 수) / 9
```

위 식에서 평균은 각 변수의 절대 차이를 그 변수의 IQR로 나눈 뒤 계산합니다. IQR이 0이거나 계산 불가능한 변수는 분모 1을 사용합니다. 각 환자의 최근접 후보 최대 10명을 미리 계산하고, 화면에서는 후보 수·거리·공통 변수 조건을 적용한 무방향 연결의 합집합을 표시합니다. 후보 탈락 시 10명 밖에서 보충하지 않습니다.

기본값은 후보 5명, 거리 상한 0.50, 공통 유효 변수 5개입니다. 다른 환자가 선택한 연결도 포함되므로 연결 수는 5개를 넘을 수 있습니다. 거리·벌점·가중치는 탐색용 설정이며 임상적으로 검증된 환자 유사도나 치료효과 점수가 아닙니다. 공통 변수의 구성과 실제 투약/가상 기준점을 함께 확인해야 합니다.

보정값과 치료 후 결과는 거리 계산에 사용하지 않습니다. 배치 초기화에서만 중앙값 대체를 사용합니다. 배치는 고정되어 있으며 시각적 근접성이 거리 점수를 정확하게 보존하지 않습니다. 시간 경과 애니메이션은 이 버전에 포함하지 않습니다.

## 데이터 관리

이 저장소에는 환자 데이터와 데이터가 내장된 생성 HTML을 포함하지 않습니다. `data/`, `output/`, CSV, Excel, 이미지 등은 `.gitignore`에 등록돼 있습니다. 생성 HTML에는 가명과 임상 측정값이 포함되므로 원본 데이터와 같은 접근 통제가 필요합니다. 프로그램은 입력 데이터를 외부로 전송하지 않습니다.

## 검증

```bash
python -m unittest discover -s tests -v
```

저장소 테스트는 합성 데이터만 사용합니다. 기존 업로드 데이터의 1,328개 노드·4,365개 연결·46개 고립 노드를 재현했고, Chromium에서 호버·클릭·비교·필터·검색·확대·축소 동작을 검증했습니다. 원본 데이터가 저장소에 없으므로 이 실데이터 검증을 실행하려면 해당 파일이 로컬에 필요합니다.

현재 구현은 거리 행렬과 배치에 O(N²) 메모리·연산을 사용합니다. 대규모 코호트에서는 후보 검색과 배치 방식의 확장이 필요합니다.
