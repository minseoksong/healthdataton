연결 기준과 해석 범위

비교 변수: 나이, 체중, 수축기혈압, 심박수, SpO₂, Creatinine, BUN, 나트륨, 칼륨. 원본 값이 없거나 해당 missing_outlier 플래그가 1이면 유효 비교에서 제외합니다. 보정 파일의 값·시각, 치료 후 결과는 거리 계산에 사용하지 않습니다. 입실·기준점의 이상 플래그가 있는 환자도 전체 표시하며 상세 패널에 경고합니다.

거리 = 공통 유효 변수의 |차이| / 전체 환자의 해당 변수 IQR을 평균한 값 + 0.3 × (9 − 공통 유효 변수 수) / 9. 기본적으로 공통 변수 5개 이상이고, 성인/미성년 플래그가 같은 환자만 비교합니다. 0.3 결측 벌점과 거리 상한 0.50은 탐색용 설정이며 임상적으로 검증된 기준이 아닙니다. 성별·진단·기계환기 여부를 일치시키지는 않습니다.

각 환자의 가장 가까운 후보 최대 10명을 미리 계산했습니다. 선택한 후보 수와 거리·공통 변수 조건을 통과한 연결의 합집합을 표시합니다. 다른 환자로부터 선택될 수 있어 실제 연결 수는 후보 수보다 많을 수 있습니다. 공통 변수 수 조건은 미리 선정한 후보에 적용하며 후보를 추가로 보충하지 않습니다.

시각적 위치는 기본 연결에 맞춘 고정 배치입니다. 배치 초기화에만 중앙값 대체를 사용했고, 거리에는 사용하지 않았습니다. 화면의 군집은 진단 집단이나 검증된 임상 유형을 의미하지 않습니다. 노드가 가까워 보이는 정도보다 연결 거리와 변수별 차이를 확인하세요.

전체 지도는 성별·심부전·기계환기 일치 조건을 적용하지 않고 부분 관측도 허용합니다. 원본 시각 기준은 환자마다 실제 투약 또는 입실 후 6시간으로 다를 수 있으며, 연결을 치료효과 비교에 직접 사용할 수 없습니다.
